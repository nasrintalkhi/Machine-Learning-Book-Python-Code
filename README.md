# کدهای پایتون کتاب یادگیری ماشین

این مخزن شامل کدهای پایتون، فایل‌های Jupyter Notebook و پیاده‌سازی‌های عملی مثال‌های کتاب «یادگیری ماشین» است. تمامی کدها جهت یادگیری مباحث مختلف از پیش‌پردازش تا الگوریتم‌های پیشرفته دسته‌بندی و رگرسیون تنظیم شده‌اند.

## راهنمای اجرا

برای اجرای صحیح فایل‌های نوت‌بوک، ابتدا کتابخانه‌های مورد نیاز را از طریق فایل `requirements.txt` نصب کنید:
```bash
pip install -r requirements.txt
