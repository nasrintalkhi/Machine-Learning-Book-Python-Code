# کدهای پایتون کتاب یادگیری ماشین

به مخزن کدهای پایتون کتاب یادگیری ماشین خوش آمدید. در این مخزن، تمام دفترچه‌های ژوپیتر (Jupyter Notebooks)، کدهای پایتون و داده‌های مربوط به مثال‌های عملی کتاب قرار داده شده است.

---

## راهنمای استفاده و وابستگی‌ها (Dependencies)

برای اجرای کدهای این کتاب، پیشنهاد می‌شود از محیط Jupyter Notebook یا Google Colab استفاده کنید.

تمام کتابخانه‌ها و بسته‌های مورد نیاز برای اجرای کدها در فایل `requirements.txt` مشخص شده‌اند. برای نصب یک‌جای تمام وابستگی‌ها، دستور زیر را در ترمینال یا خط فرمان اجرا کنید:

</div>

pip install -r requirements.txt
